# 📁 App cho con

Thư mục lưu trữ toàn bộ dữ liệu dùng để tạo app/web học tập cho con.

## Cấu trúc

| Thư mục | Dùng để lưu |
|---|---|
| `01-y-tuong/` | Ý tưởng, yêu cầu, mô tả app muốn làm (tên app, độ tuổi, mục tiêu) |
| `02-du-lieu/` | Nội dung học: từ vựng, câu hỏi, bài tập, truyện… (file .txt, .csv, .xlsx, .json) |
| `03-hinh-anh-am-thanh/` | Hình ảnh, âm thanh, icon dùng trong app |
| `04-apps/` | File app hoàn chỉnh (HTML) – mở trực tiếp bằng trình duyệt |

## Cách dùng nhanh

1. Ghi ý tưởng app vào `01-y-tuong/` (ví dụ: `app-hoc-tu-vung.md`).
2. Đưa dữ liệu học vào `02-du-lieu/`.
3. Nhờ Claude tạo app → file app được lưu vào `04-apps/`.
4. Mở file `.html` trong `04-apps/` bằng Chrome/Edge để dùng.

## Quy tắc đặt tên file

- Viết không dấu, dùng gạch ngang: `tu-vung-dong-vat.csv`
- Có thể thêm ngày: `2026-11-18-app-dem-so.html`
